# Support and Community

CaimanDB is developed as an open-source community project.

## Before asking for help

Check:

1. [`README.md`](README.md) for installation and quick start instructions.
2. [`docs/`](docs/) for technical documentation.
3. [`docs/known-limitations.md`](docs/known-limitations.md) for current limitations.
4. Existing GitHub issues and discussions.

## Bug reports

Use the bug report template when the problem can be reproduced. Include the CaimanDB version, operating system, Go version, relevant configuration and a minimal reproduction when possible.

## Feature requests

Explain the problem first, then describe the proposed solution. For NQL changes, include example syntax and expected behavior.

## Questions and design discussions

Use GitHub Discussions for questions, architecture proposals and broader design conversations when that feature is enabled in the repository.
