# Code of Conduct

## Our standard

CaimanDB is an open-source project. We want contributors, maintainers and users to be able to participate without harassment or discrimination.

Participants are expected to:

- Be respectful and constructive.
- Discuss technical decisions with evidence and good faith.
- Welcome different levels of experience.
- Keep criticism focused on code, proposals and ideas rather than people.
- Respect project, platform and community rules.

Unacceptable behavior includes harassment, personal attacks, discrimination, intimidation, deliberate disruption and publishing private information without permission.

## Enforcement

Project maintainers may remove or edit contributions that violate this code of conduct and may restrict participation when necessary to keep the project constructive and safe.

Serious or repeated issues can be reported privately through the security/contact channel described in [`SECURITY.md`](SECURITY.md).

## Scope

This code applies to project repositories, issue trackers, pull requests, discussions, documentation and other spaces used for CaimanDB community work.
